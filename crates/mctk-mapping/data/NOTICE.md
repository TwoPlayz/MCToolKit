# Mapping data provenance

`mappings.nbt.gz` (the Java <-> Bedrock block states and the biome ids) is generated by
`mctk-gen blockmap-emit` (`crates/mctk-gen/src/blockmap.rs`) from the games themselves; it uses
no third-party mapping data.

- Java blocks, properties and defaults: the `--reports` output of the Java 26.3 server.
- Bedrock blocks and states: probed on the real Bedrock Dedicated Server 1.26.61.
- Which Java state is which Bedrock state: both servers upgrade the same pre-flattening
  (numeric id, data value) blocks, which relates the two editions' states through their shared
  ancestor (`mctk-gen legacy-gen` / `legacy-read` and `mctk-convert`'s `legacy_blocks`). What the
  legacy blocks do not teach (directions, doors, beds, signs and the blocks added since) is
  written as rules in `blockmap.rs`, and every result is checked against the Bedrock registry.
- Biome ids: the ids the Bedrock server saved for each biome, and the legacy biome ids, which
  are the same numbers in both editions.
## Items

`items.tsv` is generated by `mctk-gen items-emit` (`crates/mctk-gen/src/items.rs`): the Java 26.3 item list, with each item's Bedrock name (most are the same; the renames and the colour data values of beds and banners are written there as rules).

## Entity definitions

`entities.tsv` is generated by `mctk-gen entity-plan` / `entity-read` (`crates/mctk-gen/src/entities.rs`): the Bedrock server summons every entity type (as it spawns, and as a baby) and the `definitions` it saves for each are recorded as they are. Types the server cannot summon (projectiles) have no definitions.

## Worlds from before Java 1.13 / Bedrock 1.2.13

The numeric block and item tables (`mctk-registry/data/legacy`) were read back from the games: a real Java server and a real Bedrock server each upgraded a world holding every id and data value. The old string ids (`minecraft:log`) and the pre-1.11 entity names (`Pig`) come from the Java game's own data fixers (`crates/mctk-gen/java/DumpLegacy.java`). Nothing here is copied from another project.

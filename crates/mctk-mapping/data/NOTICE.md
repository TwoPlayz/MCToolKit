does not use any data from Universal Minecraft Tool.

As GeyserMC notes, these mappings describe Minecraft, whose data belongs to Mojang/Microsoft;
neither GeyserMC nor this project relicenses it.

Java state ids are rebuilt as the game assigns them: blocks in registry order, and within a
block every combination of its properties (sorted by name, values in declared order, last
property varying fastest). The generator refuses to write a table unless the state count
matches GeyserMC's and every log `axis` agrees with Bedrock `pillar_axis`.

## Items

`items.tsv` is generated by `examples/generate_items.rs` from GeyserMC/mappings `items.json` @ `b4cec82d49fe75f222e1ad6dc0fd2a23ee89626c` (MIT, (c) GeyserMC; licence text above). It lists, per Java item, the Bedrock identifier and data value.


## Entity definitions

`entities.tsv` is generated by `examples/generate_entities.rs` from the vanilla entity behaviour files in Mojang/bedrock-samples @ `15701fa9c13923f12662984c32c124327e40e3d3` (`behavior_pack/entities`). Those files are subject to the Minecraft EULA, so they are not copied here: the tool resolves each entity's spawn event and keeps only facts, namely the entity identifier and the names of the component groups a new adult (or baby) starts with. Checked against real actors in a Bedrock 1.26.60 world (rabbit, squid).

## Worlds from before Java 1.13 / Bedrock 1.2.13

`legacy_blocks.tsv` and `legacy_items.tsv` come from `data/pc/common/legacy.json` in [PrismarineJS/minecraft-data](https://github.com/PrismarineJS/minecraft-data) @ `bd8b5c6048e5af9694374b83f25f5b4aade619cc` (MIT, (c) PrismarineJS; a few spellings are adjusted in `src/legacy.rs`). They give, for each numeric block or item id and data value, the current name and block state.

`legacy_biomes.tsv`, `legacy_ids.tsv` and `legacy_entities.tsv` list facts (numeric biome ids, old string ids, old entity names) taken from Chunker's legacy resolvers (MIT, (c) Hive Games; see `crates/mctk-chunker/LICENSE-CHUNKER`).

`legacy_bedrock_blocks.tsv` comes from `r12_to_current_block_map.bin` in [pmmp/BedrockData](https://github.com/pmmp/BedrockData) @ `bdb44a48fb6beffb6e9f6864f06d2232eb62b6a3` (CC0 1.0): Bedrock's own conversion of 1.12 block names and data values to current block states.
